# Sanatan Dharma AI

A web-based educational portal focused on Sanatan Dharma, Indian philosophy,
traditions, scriptures, festivals, and related concepts.

The project also includes a Dharma AI section that allows users to ask questions
and receive educational responses through the OpenAI API.

## Features

- Sanatan Dharma educational content
- Information about philosophy, traditions, scriptures, and festivals
- Dharma AI chat for asking questions
- Responsive and interactive frontend
- Node.js and Express backend
- OpenAI API integration
- Basic content and source-awareness guidelines for AI responses

## Tech Stack

- HTML, CSS, JavaScript
- Node.js
- Express.js
- OpenAI API
- dotenv

Notes

The AI is intended as an educational study companion. Answers involving scriptures, historical
claims, traditions, or philosophical schools should be checked against reliable 
primary or scholarly sources when accuracy is important.
